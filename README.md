# 한칸

하루를 거창하게 관리하지 않고, 오늘 필요한 한 칸만 채우는 오프라인 Android 앱입니다.

## 1.1.0 주요 기능

- `오늘`과 `기록` 두 영역으로 단순화된 개인 대시보드
- 오늘의 한 가지 저장·수정·완료·완료 취소
- 날짜 기반 연속 달성 및 누적 완료 기록
- 10·25·50분 집중 프리셋과 일시정지·재개
- 앱 재생성·백그라운드 복귀 후에도 이어지는 집중 세션
- 날짜별 빠른 메모와 최근 기록 보기
- 가족과 함께할 짧은 활동 추천
- Android 공유 메뉴를 이용한 오늘 요약 공유
- 홈 화면에서 오늘의 한 칸을 확인·완료할 수 있는 위젯
- 시스템 라이트/다크 모드, 회전·넓은 화면 대응
- 로그인, 광고, 분석 SDK, 네트워크 권한 없음

모든 기록은 앱의 로컬 저장소에만 남습니다.

## 설치

GitHub Releases에서 최신 `hankan-vX.Y.Z.apk`를 내려받아 Android 기기에 설치합니다.
Android 8.0(API 26) 이상을 지원합니다.

## 빌드

JDK 17과 Gradle 8.10.2가 필요합니다.

```bash
gradle testReleaseUnitTest
gradle assembleRelease
```

릴리즈 APK는 `app/build/outputs/apk/release/app-release.apk`에 생성됩니다.

## 릴리즈

정식 태그(`vX.Y.Z`)가 푸시되면 GitHub Actions가 테스트와 빌드를 다시 수행하고,
APK와 SHA-256 파일을 같은 GitHub Release에 게시합니다. 정식 서명 계보는 릴리즈
게이트에서 별도로 검증하며 개인 서명키는 공개 저장소에 포함하지 않습니다.
